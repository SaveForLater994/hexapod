
# Робот-гексапод

Проект 3DoF гексапода на базе микроконтроллера ESP32.  

## Структура репозитория

```
├── hexapod-firmware/         # Проект прошивки микроконтроллера (PlatformIO)
│   ├── lib/                  # Пользовательские библиотеки и драйверы (PCA9685, MPU6050, VL53L0X)
│   ├── src/                  # Исходный код (C): логика RTOS, кинематика, сетевой стек
│   ├── data/                 # Директория LittleFS для файлов сайта
│   ├── tests/                # Тесты проекта(Обратная кинематика и тд) 
│   └── platformio.ini        # Главный конфигурационный файл сборки PlatformIO
├── frontend/                 # Веб-интерфейс (Vue.js, Vite)
├── hardware/                 # Аппаратная часть проекта
│   ├── 3d-models/            # 3D-модели деталей корпуса и механизмов (Fusion)
│   └── schematics/           # Электрические принципиальные схемы цепей питания и I2C
├── tests/                    # Изолированные тесты
├── docs/                     # Документация и отчеты
│   └── media/                # Изображения, схемы и графики для документации
├── .gitignore
└── README.md
```

## Железо проекта

Архитектура периферии построена вокруг общей цифровой шины **I2C**, объединяющей вычислительную систему, датчики и исполнительные механизмы.

### Вычислительная система
* **Плата:** ESP32-WROOM-32 (DevKit v2, 38 пинов). Двухъядерный 32-битный процессор с аппаратным сопроцессором FPU.

### Группа движения
* **Сервоприводы:** MG996R (18 штук) с рабочим углом 180° для обеспечения 3DoF на каждую из 6 ног.
* **ШИМ-контроллеры:** Модули PCA9685 (2 штуки) — 16-канальные I2C-контроллеры, обеспечивающие аппаратную генерацию ШИМ-сигнала 50 Гц.

### Сбор данных (Сенсоры)
* **Лазерные дальномеры (ToF):** VL53L0X (2 штуки) ~для точного определения дистанции до препятствий и калибровки пуза.~
* **Датчик тока и напряжения:** INA219 для непрерывного мониторинга энергопотребления и программной защиты сервоприводов.

###  Энергосистема
Питание разделено на две ветви с общей землей (GND):
* **Источник:** Сборка из 2-х литий-ионных аккумуляторов (2S Li-ion) + батарейный отсек.
* **Плата заряда (BMS):** IP2326 — комбинированный модуль для быстрой зарядки от USB Type-C (5V -> 8.4V) с балансировкой ячеек.
* **Силовой DC-DC (для моторов):** Импульсный понижающий преобразователь XL4016E1 (настроен на 6.0V, выдерживает пиковые токи до 15-20А).
* **Логический DC-DC (для микроконтроллера):** Компактный понижающий модуль LM2596S (настроен на стабильные 5.0V для изоляции ESP32 от помех).

###  Система оповещения и индикации
* ~**Звук:** Пассивный пьезоизлучатель KY-006 (генерация ШИМ-мелодий ошибок и запуска).~
* **Свет:** Адресные светодиоды WS2812B (визуальная RGB-индикация системных состояний по одному проводу).


## Особенности проекта
* **Асинхронная двухъядерная архитектура:** Ядро 0 выделено под сетевой стек (Wi-Fi, WebSocket, отдача статики), Ядро 1 (APP_CPU) — под жесткое реальное время (алгоритмы походки, опрос I2C, генерация ШИМ).
* **Автономный Web UI:** Одностраничное приложение (Vue.js) упаковано архиватором Gzip и хранится непосредственно во Flash-памяти микроконтроллера (LittleFS).
* **Разделенная энергосистема:** Полная изоляция цепей питания логики (микроконтроллера и датчиков) от силовых цепей (сервоприводов) для защиты от электромагнитных помех и просадок напряжения.
* **Техническое зрение и стабилизация:** Наличие ToF-дальномеров для обхода препятствий и IMU-сенсора для автоматического поддержания баланса корпуса.

## Программный стек

### Прошивка (Backend)
* **Фреймворк:** ESP-IDF v6.0.2 (официальный SDK от Espressif).
* **Язык:** C
* **ОС:** FreeRTOS (детерминированное вытесняющее планирование задач).
* **Сеть:** Библиотека `esp_http_server` для реализации WebSocket-канала.
* **Файловая система:** LittleFS (хранение сжатых статических файлов сайта).

### Веб-интерфейс (Frontend)
* **Фреймворк:** Vue.js 3 — одностраничное приложение (SPA).
* **Сборщик:** Vite — компиляция, минификация и удаление неиспользуемого кода.
* **Оптимизация:** Автоматическое Gzip-сжатие бандла (HTML/CSS/JS) для загрузки в ограниченную память ESP32 (~30-50 КБ). 
* Интерфейс предназначен для горизонатальной ориентации мобильных устройств. При вертикальной ориентации пользователю должно быть предложено повернуть экран

## План тестов (Test Suite Checklist)

Проект покрывается комплексом тестов, разделенных на симуляцию алгоритмов на ПК, компонентные тесты прошивки (ESP32) и сквозные тесты взаимодействия веб-интерфейса с сервером.

### 1. Математика

#### **Google Test Suite (`ik-unit-tests`)** — автоматизированные юнит-тесты кинематики

- [ ] **Обратная кинематика (IK 3 DoF)** — вычисление углов $(\alpha, \beta, \gamma)$ по целевым координатам $(X, Y, Z)$.
- [ ] **Прямая кинематика (FK 3 DoF)** — восстановление координат $(X, Y, Z)$ по известным углам суставов для проверки Round-Trip точности.
- [ ] **Проверка границ досягаемости (Workspace Limits)** — корректная обработка ошибок `OUT_OF_REACH` и сингулярностей.

#### Math UI Check
- [x] **Qt 2D IK Visualizer (`inverse-kinematics-tests-ui`)** — графическая 2D-симуляция движения ноги в проекциях Top View $(XY)$ и Side View $(R\text{-}Z)$.
- [ ] **Simulated Hexapod Walk (`hexapod-walk-test`)** — симуляция 6 ног на плоскости и генерация походки.

### 2. Аппаратные тесты прошивки (`tests/firmware-tests` / ESP32)
- [ ] **I2C Bus Scanner (`i2c_scanner`)** — сканирование адресов устройств на шине (`0x40`/`0x41` PCA9685, `0x40` INA219, `0x29` VL53L0X).
- [ ] **PCA9685 PWM & 18-Servo Test (`pca9685_servo_test`)** — проверка генерации 50 Гц ШИМ, плавная калибровка нулей и сервоприводов MG996R.
- [ ] **INA219 Power Monitor Test (`ina219_power_test`)** — замер напряжения батареи 2S Li-Ion, тока потребления серв и определение Under-Voltage Cutoff.
- [ ] **Dual VL53L0X ToF Sensors Test (`vl53l0x_dual_test`)** — раздельная инициализация двух лазерных дальномеров через сигналы `XSHUT` с переназначением I2C-адреса.
- [ ] **WS2812B LED & Status Test (`ws2812b_led_test`)** — индикация системных режимов и ошибок с помощью светодиода RGB.




### 3. Сеть и WebSocket Сервер (Server / Hardware Network Tests)
- [ ] **Wi-Fi SoftAP / Station Connection Test** — подъем точки доступа ESP32, проверка стабильности DHCP и подключения клиентов.
- [ ] **LittleFS Web Server Test** — проверка отдачи Gzip-сжатых статических ресурсов (HTML/CSS/JS) через `esp_http_server`.

- [ ] **Multi-Client Connection Guard** — защита сервера от одновременных подключений с автоматическим сбросом зависших сокетов.
- [ ] **WebSocket Stress / Throughput Test** — нагрузочное тестирование с частотой 20–50 Гц пакетов телеметрии/управления.

### 4. Веб-интерфейс (Frontend UI Tests)
- [ ] **Virtual Joystick Output Test** — генерация координат вектора движения $(V_x, V_y, \omega_z)$ с гистерезисом мертвой зоны.
- [ ] **Telemetry Dashboard Rendering Test** — отображение заряда аккумулятора, графика тока INA219 и показателей ToF в реальном времени.
- [ ] **Connection Lost Reconnect Logic** — автоматическое переподключение WebSocket при обрыве связи с отображением индикатора оффлайн-статуса.
- [ ] **Servo Calibration UI & Live Adjustment** — интерфейс точной подгонки нулевых точек 18 сервоприводов в реальном времени.
- [ ] **Telemetry Dashboard Rendering Test** — отображение заряда аккумулятора, графика тока INA219 и показателей ToF в реальном времени.
- [ ] **Touch and Mouse Event Normalization** — стабильная обработка касаний на экранах смартфонов и кликов мыши на ПК.
