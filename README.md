# Робот-гексапод

Проект 3DoF гексапода на микроконтроллере esp32

## Структура папок

    ├── client/
    │   ├── admin-panel/
    │   └── frontend/
    ├── docs/                     # Документация проекта и компонентов
    │   └── media/                # Изображения для документации и README
    ├── fusion/                   # 3D-модели (кастомные и стоковые)
    ├── hexapod-app/              # Основное приложение управления гексаподом
    │   ├── network/              # Сетевые интерфейсы и связь
    │   └── kinematics/           # Модули обратной кинематики
    ├── ik-tests/                 # Тесты алгоритмов инверсной кинематики
    ├── schematics/               # Электрические схемы
    ├── .gitignore
    └── README.md

## Предположительный состав проекта

-  esp32 приложение для алгоритмов инверсионной кинематики и бекенда для прослушивания устройств управления
-  3д модель гексапода в Fusion
-  фронтенд админ-панель для управления и настройки робота

## Железо проекта

  * Микроконтроллер(плата): ESP32 WROOM32 DEVKIT v2 (38 пинов)
  * Сервоприводы 18 штук
    * MG996R - 12 штук
    * MG90S - 6 штук
  * Драйвер управления сервоприводами 2 штуки
  * Модуль энергии 
    * Аккумулятор+холдеры для него 
    * Понижающий преобразователь 2 штуки
  * Зуммер(пищалка для обнаружения ошибок)
  * Адресные светодиоды(также для опеределения ошибок+ подсветка)
  * Тумблер кнопка для включения
  * пластиковые 3д модели
  * Пара лазерных датчиков для обнаружения расстояния до пола с индикацией ошибок
